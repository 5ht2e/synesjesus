# Grapheme-Color Synesthesia (GCS) Training

Main reference study: [Adults Can Be Trained to Acquire Synesthetic Experiences](https://pmc.ncbi.nlm.nih.gov/articles/PMC4235407/)

How to do GCS training:
1. Learn GCS associations using [this chrome extension](https://chromewebstore.google.com/detail/rainbow-text/jhkgcmdmjneppikhcokmmgjodcgcgdjp?pli=1). You can customize the associations, but make sure you stick with them once you decide. Do flashcards for at least a few hours to learn the associations.

2. Export your settings from the Rainbow Text chrome extension. Import that same settings file to do synesthesia n-back on this site: https://5ht2e.github.io/synesjesus/synesthesianback/index.html.

3. In addition to synesthesia n-back and flashcard training, read text in hardcore mode using the Rainbow Text extension.

For timely results, spend at least 30 minutes per day in total on synesthesia training.
